阅读 AgentHot 不需要注册或登录。本站未接入广告追踪或第三方访客统计，不出售个人信息。

## 1. 浏览器本地数据

收藏、已读记录、深浅色设置、最近搜索（最多 10 条）、更新日志已读状态和反馈草稿主要保存在当前浏览器里；列表位置、滚动位置和展开状态保存在当前标签页的会话存储里。本站不提供读者账户或跨设备同步，清除浏览器数据会清除这些记录。打开收藏页时，收藏条目的 ID 会发送到本站服务器，以核对内容是否仍可用；发起搜索时，搜索词会发送到本站服务器，以返回结果。

## 2. 反馈与管理登录

提交反馈时，正文、选填邮箱、页面地址和主动附上的截图会保存在本站服务器，由运营者用于处理反馈。当前未开启飞书转发。请不要提交密码、密钥或其他不必要的敏感资料。

服务器保存由网络地址和浏览器类别计算的标识，用于限制滥用。反馈目前没有自动到期删除机制；你可以通过反馈页申请查询、更正或删除自己提交的资料。使用 GitHub Issues 时，内容通常公开，请勿在那里提供隐私资料。

后台仅供管理员使用。管理员登录会设置会话 Cookie，匿名阅读不需要该 Cookie。

## 3. 服务与日志

本站使用 Hostinger 服务器托管网站及数据库，并使用 Cloudflare 提供域名解析。服务请求可能包含网络地址、访问时间、请求路径、搜索参数和浏览器信息。本站应用容器的运行日志按容量轮换，每个容器最多保留三个约 10 MB 的日志文件，没有固定的按天保留期限；服务商依据其自身配置和政策处理基础设施数据。

当前未设置第三方广告或行为分析脚本。本站处理新闻摘要时使用模型；读者打开页面不会触发模型调用，反馈资料不作为新闻分析输入。

## 4. 第三方内容

本站展示第三方来源的摘要、配图和原文链接。配图通常由本站代理加载；打开第三方原文或直接加载其资源时，对方可能接收到网络地址及浏览器请求信息，并适用对方的隐私政策。

## 5. 联系与更正

如需了解或更正本站的数据处理方式，请使用[反馈页](/feedback)。涉及个人资料的请求请只提供定位该资料所需的信息，不要在公开 GitHub Issues 中上传身份证明。
