AgentHot 聚合公开的 Agent 相关信息，提供中文摘要、阅读索引与原文链接。网页、RSS、公开 API 与 MCP 可匿名阅读。当前为试运行，收录量和来源覆盖有限，自动更新与定时报告尚未启用。

## 1. 内容与版权

中文标题、摘要、分类、评分和推荐理由包含模型生成内容，可能有误，不代表独立复现或事实背书。项目方报告的结果不等同于本站验证结果，重要信息请查看原始来源。

原文、配图、商标和第三方材料的权利归各自权利人所有。首版仅展示摘要、配图和原文链接，不开放来源全文。本站代码的开源许可不等于第三方内容的再分发许可。

## 2. 来源方的更正与下架

来源方或读者可以通过[反馈页](/feedback)提出更正、下架或展示方式调整请求，请提供相关页面和问题说明。

## 3. 使用本站的数据

可使用本站公开页面和只读接口阅读、检索和引用信息。引用时请保留来源和原文链接，并区分原始材料与本站生成的摘要。转载、商业使用或批量再分发第三方材料时，应自行取得相应授权，不能把访问本站视为已获权利人的许可。

## 4. 接口与频率

请遵守响应中的缓存期限；收到 429 时遵守 Retry-After，不要并发重试、绕过限制或尝试访问未授权的管理接口。本站可能因维护或滥用防护调整服务。

## 5. 试运行边界

本站按现状提供，不保证内容完整、准确、及时或持续可用。请勿把自动评分作为投资、医疗、法律或其他重要决定的唯一依据。
